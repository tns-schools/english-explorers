# TNS English Explorers

**Tarbyh Namouthajiyah Schools · National Track | Grades 1–5**
*Listen. Speak. Read. Spell. Explore.*

A free, static English-learning website for primary ESL students: 9 learning sections × 5 levels, 250 activity sets,
50 original reading passages, an optional Find Your Level check, prerecorded natural audio, local progress and achievements,
anonymous analytics, and a secure Admin Analytics Dashboard.

- No student accounts, no microphone, no personal information.
- Runs on GitHub Pages. Analytics use a separate Supabase project (not connected to NVS English Quest).

| Document | What it is for |
|---|---|
| `docs/DEPLOYMENT.md` | Publishing the site, setting up Supabase and the dashboard, live checks |
| `docs/MAINTENANCE.md` | Project structure, editing content, regenerating audio |
| `docs/QA-REPORT.md` | What was tested, results, and what still needs a person |
| `docs/AUDIO-LISTENING-CHECKLIST.md` | Recordings a person should listen to |
| `docs/TEACHER-SOUND-RECORDING.md` | Optional teacher letter-sound recordings |
| `docs/CONTENT-INVENTORY.md` | Every section, level and activity |
