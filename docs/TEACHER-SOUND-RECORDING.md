# Recording the letter sounds (for one teacher, about 20 minutes)

Phonics Planet already works fully with whole-word audio. These short recordings add an optional **“Hear the sound”** button. No question depends on them.

**You need:** a phone and a quiet room. **Tip:** record all sounds in one sitting so they sound the same.

1. Open the phone's voice recorder. Hold the phone about 20 cm from your mouth.
2. For each row below, say the **sound only** (not the letter name, and no added “uh”). Say it **once**, clearly.
3. Save each recording with the **file name** in the first column (for example `m.m4a`). Any audio format is fine.
4. Put all files in one folder and send it. The import script trims, levels and installs them automatically.

| File name | Sound | As in | How to say it | ✓ |
|---|---|---|---|---|
| `a` | /a/ | ant | Short a, as at the start of ant. Do not say the letter name. | ☐ |
| `b` | /b/ | bus | A short, crisp b. No 'buh' — keep it as short as possible. | ☐ |
| `c` | /k/ | cat | A short, breathy k. No 'kuh'. (Same sound as k.) | ☐ |

**Most important:** short sounds (b, c/k, d, g, p, t, ch, j) must be **short and crisp** — say “p”, not “puh”. Continuous sounds (m, n, s, f, sh, z, v, l, r) can be held for about one second.
