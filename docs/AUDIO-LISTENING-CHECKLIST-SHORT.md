# Short audio listening checklist (50 representative recordings)

Priority review covering every audio-dependent section and all five levels. Listen in order; tick ☐ when correct, note anything wrong.
Interactive version: **review/audio-review-short.html** (play, mark OK / Problem, copy results).
If several problems appear in one group, we switch to the **full checklist** (`docs/AUDIO-LISTENING-CHECKLIST.md`, 557 items) for that group.

**About isolated phonemes:** the computer voice is not used for isolated letter sounds (agreed earlier). Those will be the teacher's recordings
(`docs/TEACHER-SOUND-RECORDING.md`) and get their own quick listen after import. Group 1 checks the phonics WORDS the questions rely on.
